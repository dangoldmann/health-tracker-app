# API

NestJS backend scaffold for the Health Tracker monorepo.

## Scripts

- `npm run dev --workspace api`
- `npm run build --workspace api`
- `npm run test --workspace api`
- `npm run test:e2e --workspace api`
- `npm run prisma:generate --workspace api`

## Environment

Copy [`apps/api/.env.example`](./.env.example) into a local `.env` file and fill in the Postgres and Supabase values before running the app.
